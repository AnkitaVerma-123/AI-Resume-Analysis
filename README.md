AI Resume Analyzer – Smart Resume Screening System

📌 Project Overview

AI Resume Analyzer is a web-based Smart Resume Screening System developed using Python and Flask. It helps users analyze their resumes by extracting information, identifying skills, detecting missing skills, and providing suggestions for improvement based on a given Job Description.

The main objective of this project is to make the resume screening process easier and help candidates improve their resumes according to job requirements.

Demo link: https://ai-resume-analysis-cphv.onrender.com
🎯 Objectives

- To automate the basic resume screening process.
- To extract text from PDF and DOCX resumes.
- To identify technical skills mentioned in resumes.
- To detect missing skills based on job descriptions.
- To provide resume improvement suggestions.
- To display resume analysis results.

Step 3: Install Required Libraries

Step 5: Open in Browser

Open your browser and visit:

http://127.0.0.1:5000/

📊 Working Process

1. User opens the AI Resume Analyzer application.
2. User logs in or creates an account.
3. User uploads a resume in PDF or DOCX format.
4. User enters the Job Description.
5. The system extracts resume text.
6. The system identifies matched and missing skills.
7. The system displays the analysis results and suggestions.
